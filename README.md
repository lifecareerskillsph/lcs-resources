# Life & Career Skills - Teacher Resources

Instructional resources for Grade 11 Life and Career Skills, developed with reference to the DepEd Strengthened Senior High School Curriculum for Life and Career Skills (2025).

## Quarter 1 Performance Task

### 3-Week Integrative Wellness Tracking

Current version: **August 2026**

The current version includes refinements to grading, student data-entry fields, and reflection items to improve usability and alignment with the Quarter 1 learning competencies.

### Resources

**Teacher Guide**  
Setup, distribution, monitoring, and detailed grading workflow for the Q1 PeTa.

**Student Tutorial**  
Student-facing guide for opening, navigating, completing, and submitting the Wellness Tracker.

> Please use the resources linked here so that all classes are working from the same updated version.

## Version Updates

The August 2026 version includes:

- progress-based grading in place of the earlier binary grading approach
- updated student-name handling for different name formats
- dropdown fields for Grade and Section
- chip dropdowns for selected tracker fields
- removal of redundant response options
- review and revision of reflection questions for alignment with the Quarter 1 learning competencies
